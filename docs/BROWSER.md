# Браузер: почему он не живёт вместе с сервисом и куда его вынести

## Что случилось

Задача доходила до шага «Открываю higgsfield.ai в браузере», и сервис
перезапускался. Каждые четыре минуты: задача возобновлялась, снова доходила до
браузера, снова роняла процесс.

Причина не в коде браузера. Chromium на пустой странице занимает около 150 МБ,
плюс вкладка и профиль. На инстансе с 512 МБ, где уже работают Python,
SQLAlchemy, бот и задачи, этой памяти нет. Нехватку памяти нельзя поймать
через `try/except`: ядро снимает **весь процесс**, а не отдельный вызов.

Поэтому теперь память проверяется ДО запуска (`MemAvailable` и лимит cgroup), и
канал честно отказывает, называя выход. Сервис при этом жив.

## Три рабочих варианта

### 1. Без браузера (по умолчанию)

Генерация через Higgsfield идёт по OAuth и по ключу — браузер им не нужен.
Он требуется только там, где у площадки нет API: часть публикаций и поиск
без ключа.

Ничего настраивать не нужно. `NEXUS_INSTALL_CHROMIUM` оставьте пустым:
Chromium не будет ставиться даже при сборке, и деплой станет легче на ~150 МБ.

### 2. Облачный браузер (рекомендуется, если браузер нужен)

Браузер работает у провайдера, наш сервис только отдаёт команды по сети —
памяти это почти не стоит.

```
NEXUS_BROWSER_CDP = wss://<логин>:<пароль>@<хост>:9222
```

Подходит любой сервис, дающий CDP-эндпоинт (Bright Data Scraping Browser,
Browserless и подобные). Значение вписывается **только** в Render →
Environment: это доступ, ему не место ни в коде, ни в репозитории, ни в чате.

### 3. Отдельный сервис с большей памятью

Если браузер нужен свой, разверните его отдельным сервисом (на этом же или на
другом аккаунте Render) с тарифом от 2 ГБ и задайте там:

```
NEXUS_INSTALL_CHROMIUM = 1
NEXUS_BROWSER_MIN_MB   = 800
```

Основной сервис остаётся лёгким и обращается к нему через `NEXUS_BROWSER_CDP`.

## Сколько памяти занимает сам сервис

SDK провайдеров грузятся лениво — в момент первого обращения к провайдеру, а
не при старте. Вместе они занимали около 110 МБ постоянно:

| Пакет | Память |
|---|---|
| `google.generativeai` | ~64 МБ |
| `anthropic` | ~24 МБ |
| `openai` | ~20 МБ |

После запуска сервис занимает около 70 МБ вместо ~180. Это и есть та память,
которой не хватало всему остальному.

## Как проверить

`/hixiit` — строка про браузер скажет одно из трёх: работает, не установлен,
или не хватает памяти с указанием, сколько её свободно.
