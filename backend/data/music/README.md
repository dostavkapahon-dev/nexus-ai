# Музыкальная библиотека (роялти-фри)

Клади сюда бесплатные треки без авторских прав (.mp3/.m4a/.wav).
Источники: YouTube Audio Library, Pixabay Music, Free Music Archive.

Теги — в `tags.json`:
{
  "energetic_beat.mp3": {"mood": "energetic", "bpm": 120},
  "calm_piano.mp3":     {"mood": "calm", "bpm": 80}
}

Настроения: energetic / calm / fun / dramatic / universal.
Агент выбирает трек по настроению ниши КОДОМ, без вызова модели.
