## 2. Где именно рвётся цепочка на сервере

MCP авторизуется **OAuth-сессией пользователя**, а не API-ключом
(официальный адрес `https://mcp.higgsfield.ai/mcp`). Поэтому:

* из среды с OAuth (эта сессия) MCP работает — доказано выше;
* с сервера Render тот же MCP отвечает `-32603`, затем `ConnectTimeout` —
  сессии там нет и быть не может без интерактивного входа.

Значит на сервере остаются два пути: REST по ключу и браузер в залогиненном
аккаунте. Оба чинились в этой сессии (PR #119, #120).

## 3. Ограничение проверяющей среды

Скачать готовый файл из этой среды нельзя: CDN `d8j0ntlcm91z4.cloudfront.net`
закрыт egress-политикой песочницы. Это ограничение проверяющего, а не системы:
ссылка выдана платформой, статус `completed`, размеры кадра получены.
Проверка «файл скачан и доставлен в Telegram» выполняется на сервере.
