# API LIMITATIONS — что невозможно из-за платформ

Обозначение: 🔵 **BLOCKED_BY_API** — ограничение платформы, а не нашего кода.
Фиктивных решений («моков») для таких функций не создаём.

## Instagram (Meta Graph API)

| Функция | Статус | Причина / требование |
|---|---|---|
| Чтение личного (Personal) аккаунта | 🔵 BLOCKED_BY_API | Graph API работает только с Business / Creator, привязанным к Facebook Page |
| Публикация Stories | 🔵 BLOCKED_BY_API | Требует расширенных permissions и App Review Meta |
| Полный набор insights | 🔵 BLOCKED_BY_API | Часть метрик — только после App Review |
| Чтение чужого аккаунта | 🟡 частично | Business Discovery — только для Business/Creator аккаунтов |
| Долгий токен | ⚪ не реализовано у нас | Обмен на long-lived (60 дней) + периодическое продление — наша задача, не ограничение API |
| Webhooks (комментарии, упоминания) | ⚪ не реализовано у нас | API поддерживает; нужен публичный HTTPS-эндпоинт и верификация |

**Permissions для работы:** `instagram_basic`, `instagram_manage_insights`,
`pages_read_engagement`, `pages_show_list`; для публикации дополнительно
`instagram_content_publish`, `pages_manage_posts`.

## Общие ограничения среды

| Ограничение | Влияние |
|---|---|
| Egress-прокси среды разработки блокирует instagram.com / youtube.com | Живые проверки чтения невозможны из сессии аудита; проверять только на развёрнутом сайте или через удалённый CDP-браузер |
| Render free: 512 МБ RAM | Локальный headless Chromium работает впритык → рекомендуется удалённый браузер (`NEXUS_BROWSER_CDP`) |
| Render free: эфемерная ФС | 🟢 Решено внешней базой (`DATABASE_URL`) — см. `PROJECT_STATE.md` |

## Браузерный путь — что он даёт и чего не даёт
**Даёт:** чтение публичных профилей и постов, публикацию через веб-интерфейс без API-токенов.
**Не даёт:** приватную статистику (охваты, удержание) без залогиненной сессии
(`NEXUS_BROWSER_STORAGE_STATE` с cookies) и обход двухфакторной аутентификации.

## Безлимит Higgsfield не работает через API (проверено 09.09.2026)

Живой запрос к аккаунту: план `ultimate`, 1199.85 кредита, `models_explore`
с `unlim: true` возвращает `unlim: {"available": false}`. В тарифе безлимитные
пакеты (365-DAY UNLIMITED, 7-Day Unlimited) помечены **«Available on web»**, а
`unlim_trial_in_mcp_active: false`.

Важно: безлимит у аккаунта **есть** — он куплен на сайте и покрывает фото-модели (`soul_2`, `gpt_image_2`, `nano_banana`, `nano_banana_pro`, `seedream`, `flux_2`, `kling_omni_image`). Ноль здесь — это ответ API о том, может ли вызывающая сторона тратить его **прямо сейчас через этот канал**, а не об отсутствии безлимита вообще.

Практический вывод: маршрут через MCP сам по себе **не даёт** безлимита. И MCP, и REST по
ключу тратят один и тот же баланс кредитов. Поэтому искать `HIGGSFIELD_MCP_URL`
ради экономии смысла нет — при выборе пути это больше не аргумент.

Когда безлимит доступен, система подменяет выбранную модель на равноценную по роли из покрытых (`hixiit.unlim_swap`) — иначе кадр оплачивался бы кредитами при лежащем без дела безлимите.
