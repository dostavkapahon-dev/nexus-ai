## 2. 🟠 Подключить Higgsfield — действие владельца

Для сервера нужен **ключ + секрет**, а не MCP: MCP авторизуется OAuth-токеном,
который истекает, и продлевать его на Render некому.

1. https://cloud.higgsfield.ai → API keys → Create key. Секрет показывается один раз.
2. Render → `nexus-ai` → Environment:
   - `HIGGSFIELD_API_KEY` = key
   - `HIGGSFIELD_SECRET` = secret
3. Проверить в Telegram: `/hixiit` — строка «API-ключ» станет ✅.

Одного ключа без секрета недостаточно: запрос отклоняется, `/hixiit` скажет прямо.

## 5. 🟡 Cloud Code как единая точка входа

Сейчас свободный текст сначала проходит роутер намерений (`core/intent.py`):
готовые команды выполняются напрямую, и только то, что не подошло ни под одну,
уходит дирижёру через `/director`. Это дёшево по токенам и предсказуемо, но
формально ТЗ описывает дирижёра как единственную точку решения.

Рекомендация: оставить как есть и понаблюдать. Отправлять **каждое** сообщение
в дирижёра — это лишний вызов дорогой модели на «покажи очередь» и заметно
медленнее для простых команд. Менять стоит, только если роутер начнёт заметно
ошибаться.
