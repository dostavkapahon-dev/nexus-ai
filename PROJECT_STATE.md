## Что работает

- Telegram как основной интерфейс: команды, кнопки, приём медиа, согласование
  контента с кнопками, проверка владельца, устойчивость к 409/401.
- Cloud Code (`core/marketing_director.py`) с инструментами: `delegate`,
  `web_search`, `open_url`, `research`, `run_browser`, `analyze`,
  `make_image`, `make_video`, `publish`.
- 11 агентов через реестр, лог каждого вызова модели с токенами и стоимостью.
- Очередь публикаций с повторами, планировщик (Asia/Almaty), публикаторы.
- HIXIIT (`core/hixiit.py`): выбор модели по каталогу аккаунта, цепочка
  MCP → REST → браузер → бесплатная картинка, внятные причины отказа.
- Память разборов: результат анализа Instagram/YouTube/TikTok сохраняется в
  историю исследований (`kind="account"`) и подставляется в промпты — сводка
  рынка (`research_store.market_context`) и ответы в чате
  (`intent.memory_block`). На вопрос «какая у меня ниша?» бот отвечает по
  сохранённому профилю, а не догадкой.
- 681 автотест зелёный.
