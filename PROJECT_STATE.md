## Что это

FastAPI-бэкенд + React-фронтенд, деплой на Render. Автоматизация контента:
ниша → анализ → контент-план → текст → визуал → проверка → Telegram → публикация.
Основной интерфейс — **Telegram**. Сайт необязателен.

## Что работает

- **Главная цепочка Telegram → Cloud Opus → агенты → HIXIIT → Telegram** — починена
  (была разорвана в трёх местах, см. ERRORS.md #1–#4).
- 11 специализированных агентов + логирование каждого вызова LLM (см. AGENTS.md).
- Роутинг моделей `core/ai_router.py`: экономный/премиум режим, фолбэк-цепочка.
- Пайплайн ниши `core/orchestrator.py` и фабрика роликов `core/content_factory.py`.
- Планировщик: тренды 09:00, фабрика 09:30, генерация 10:00, публикация 19:00,
  отчёт 22:00, недельный отчёт вс 20:00 (Asia/Almaty).
- Публикация: Telegram/Instagram/VK по API, остальное — через браузер-агента.
- Очередь публикаций: `/api/queue` + кнопки в Telegram.
- Веб-дашборд (`frontend/dist` собран и закоммичен).

## Что НЕ работает / требует действий от владельца

1. **Память стирается при рестарте.** Нужен `DATABASE_URL` на Postgres в Render.
   Код готов, инфраструктуру создаёт владелец. TODO.md #1 — критично.
2. **HIXIIT через MCP не подключён на сервере.** Нужны `HIGGSFIELD_MCP_URL` и
   `HIGGSFIELD_MCP_TOKEN` в Render. Аккаунт живой (план ultimate, 1200 кредитов —
   проверено), но у процесса на Render своего доступа к MCP пока нет.
   До этого работают запасные пути. TODO.md #2.
3. Браузерный путь (Instagram/TikTok/YouTube, HIXIIT без ключа) требует включённого ПК
   со `start_agent.bat`. Это ограничение архитектуры, не дефект.

## Как проверить

```bash
cd backend
pip install -r requirements.txt
python tests/test_smoke.py          # 5 тестов
uvicorn main:app --port 8000        # сервер
```
В Telegram: написать задачу словами → должен прийти ответ с медиа и кнопками.
`/hixiit` → честный статус генеративного слоя.
